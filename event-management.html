Capabilities

One dashboard for the whole event

Everything the day needs, from the first planning session to the last guest through the door.

Multi-Event Hosting

Run as many events as you need from a single account, each moving through its own phases — nominations, voting, closed. Duplicate a past event and its settings come with it.

Online Registration

Attendee sign-up that works independently of ticketing, so free and invite-only events are first-class. Every registration flows straight into your central contacts list.

Digital Check-In

Scan guests in at the gate or check in a whole group at once. The arrival report tells you who came, when they arrived and which entrance they used.

Event Microsites

A public site for every event with more than fifteen built-in page types — home, speakers, gallery, sponsors, FAQ, contact and the rest — all under your own branding.

Programme & Logistics

Venues with capacity and map links, speakers with bios and session details, sponsors with tier levels, plus an agenda builder and programme booklet uploads.

Live Event Feed

A real-time view of the event as it happens — arrivals, sales and activity ticking over — so you can spot a queue building before your guests complain about it.

Set Up

Build it once, run it every year

Most awards programmes are annual, and rebuilding the same structure each cycle is wasted work. Duplicate last year's event and everything comes with it — categories, sub-categories, sponsor tiers, page layout. Change the dates and you are live.

  • Full event copy including settings and structure
  • Categories and sub-categories, reorganised freely
  • Cover images, banners and poster assets per event
  • Cancel or archive an event without losing its records

How It Works

Four steps to event day

The same path every organiser takes, with the platform holding the detail so you can hold the room.

1
Create

Set up the event

Name it, set the dates, upload your cover and banner artwork, and lay out the categories — or duplicate last year's event and adjust.

2
Build

Add the programme

Enter venues, speakers and sponsor tiers, build the agenda, upload the programme booklet, and answer the FAQs people always ask.

3
Publish

Open registration

Push the microsite live and start taking sign-ups. Contacts build automatically as guests register, ready for your email and SMS blasts.

4
Run

Work the room

Check guests in by scan or in bulk, follow the live feed through the evening, and export the attendance report before you leave the venue.
